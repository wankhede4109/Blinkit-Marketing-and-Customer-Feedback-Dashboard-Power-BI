📊 Project Overview

This project is an interactive Blinkit Marketing and Customer Feedback Dashboard developed using Microsoft Power BI. It provides insights into marketing campaign performance, advertising expenditure, customer engagement, order trends, payment methods, and product categories through interactive visuals and dynamic filtering.

The dashboard contains a landing page with clickable navigation buttons that allow users to switch between the Marketing and Customer dashboards for a more organized and user-friendly experience.

🛠️ Tools & Technologies
Microsoft Power BI – Dashboard development and data visualization
DAX (Data Analysis Expressions) – Creating measures, calculated columns, and analytical calculations
DAX Calendar Table – Creating a calendar table for date-based analysis
Interactive Visuals – Bar charts, donut charts, KPI cards, maps, and other visuals
Buttons & Navigation – Interactive buttons for navigating between dashboard pages
Slicers & Filters – Filtering data by date, campaign, channel, payment method, and category
📌 Dashboard Features
1. Landing Page & Navigation
Created an interactive landing page with clickable Marketing and Customer buttons.
Enabled users to navigate between dashboard sections easily.
2. Marketing Campaign Analysis
Analyzed campaign impressions, clicks, and conversions.
Evaluated advertising spend and revenue generated by campaign.
Displayed Return on Ad Spend (ROAS) and the number of campaigns.
Compared spending across marketing channels such as App, Email, SMS, and Social Media.
Added date, campaign, and spending filters for interactive analysis.
3. Customer & Order Analysis
Analyzed customer engagement and customer feedback ratings.
Displayed total orders and order trends using KPI cards and charts.
Visualized order distribution across payment methods, including Card, Cash, UPI, and Wallet.
Used map visualizations to explore geographic order distribution.
Added filters for order dates and product categories.
📅 DAX Implementation
Created a calendar table using DAX to support date-based analysis.
Used DAX functions to build measures and calculated metrics.
Applied DAX calculations to support KPIs and dynamic visualizations.
Connected date-based filtering with the dashboard's analytical views.
🎯 Key Learnings
Building interactive Power BI dashboards.
Writing DAX measures and calculated columns.
Creating and using a calendar table.
Designing interactive navigation with buttons.
Applying slicers and filters for dynamic data exploration.
Presenting marketing and customer insights through data visualization.
💡 Project Objective

The objective of this project is to transform marketing and customer-related data into meaningful visual insights that help users understand campaign performance, advertising expenditure, customer engagement, and order behavior.
